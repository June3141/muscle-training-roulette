# ADR 0002: 何を「独立軸」にしてよいかの基準

- ステータス: **Accepted**
- 日付: 2026-08-17
- 関連: design.md §4.5, §4.2, §2 Q2

## 背景

`equipmentOptions` と `lateralityOptions` を独立軸に分離した以上（§4.2）、
「軸を切り替えたら重みも変わるべきでは」という問いが必ず出る。実際、厳密には変わる。

- ダンベルベンチはバーベルベンチより安定性要求が高く、三角筋前部の比率が上がる
- ワンハンドロウは体幹の回旋抵抗が加わり、腹斜筋が入る
- クローズグリップベンチは三頭の関与が跳ね上がる

**つまり「軸は重みを変えない」という命題は、そのままでは偽。**
必要なのは「どこまでの変化を無視してよいか」の線引きである。

## 決定

**主働筋が入れ替わらない差異のみを軸にする。**

| 差異 | 主働筋 | 扱い |
|---|---|---|
| 器具（バーベル / ダンベル / マシン / スミス） | 変わらない | **軸**（`equipmentOptions`） |
| 片手 / 両手 | 変わらない | **軸**（`lateralityOptions`） |
| グリップ幅（ワイド / ニュートラル） | 変わらない | **別種目**（軸にはしない。下記） |
| **グリップ幅（クローズ）** | **胸 → 三頭に入れ替わる** | **別種目** |
| 角度（インクライン / デクライン） | 変わらない場合が多いが `movementPattern` が違う | **別種目** |
| スタンス幅（スモウ / コンベンショナル） | 入れ替わる | **別種目** |

v1 では、軸の切り替えによる比率の変化は**無視する**。
必要になったら `equipmentModifiers` を後付けする。

```jsonc
// 将来の拡張形（v1 では実装しない）
"equipmentModifiers": {
  "dumbbell": { "deltoid_anterior": 1.2, "pectoralis_major_sternal": 0.95 }
}
```

## この基準は機械的に判定できる

上流の free-exercise-db は、**主働筋の入れ替わりを既に `primaryMuscles` に記録している。**

| 種目 | 上流の primaryMuscles |
|---|---|
| Barbell Bench Press - Medium Grip | `chest` |
| **Close-Grip** Barbell Bench Press | **`triceps`** |
| Wide-Grip Barbell Bench Press | `chest` |
| Dumbbell Bench Press with Neutral Grip | `chest` |
| Smith Machine **Close-Grip** Bench Press | **`triceps`** |

ラットプルダウンも Close-Grip / Wide-Grip / Underhand / V-Bar すべて `lats` のまま。

したがって M1 の種目統合は次の手順で自動化できる。

1. ベース名でグルーピングする
2. `primaryMuscles` が一致するものを畳んで `equipmentOptions` に入れる
3. `primaryMuscles` が異なるものは別種目のまま残す

**ただし上流の `primaryMuscles` 自体に誤りがある**（`docs/data-survey.md` の
「上流 primaryMuscles の信頼性」を参照）。M1 の健全性チェックを通した後の値を使うこと。

## 軸に分けても直積がすべて有効なわけではない

器具と片手/両手を独立軸にすると、UI は直積を提示できてしまう。
**バーベルベンチプレスに「片手」は存在しない。**

制約は器具の物理形状から決まるので、種目ごとの例外表を持たずに書ける。

| 器具 | 上半身で片手 | 理由 |
|---|---|---|
| バーベル / EZ バー / スミス | **不可** | 1 本の剛体を両手で保持する |
| ダンベル / ケトルベル / バンド | 可 | 左右が独立した器具 |
| ケーブル / マシン | 可 | プーリー 2 基、左右独立アームのイソラテラル機 |

**下半身は例外。** ここでの「片手/両手」は片脚/両脚を指し、
バーを担いだまま片脚で立てる（One Leg Barbell Squat、Smith Single-Leg Split Squat）。
判定には `movementPattern` を使う。

既知の反例が 1 件ある。上流の Smith Machine One-Arm Upright Row は
上半身のスミス片手種目で、この規則では無効になる。ガイドレールがバーを支えるので
実際には可能だが、**許すとスミスの片手ベンチプレスまで有効になる。**
1 件を落とす側を採る。

実装は `packages/data/src/combinations.ts`。

## グリップ幅を軸にしない

ワイドグリップは主働筋が変わらないので軸の候補だったが、**別種目として扱う。**

上流はグリップ違いを独立したレコードとして持っており（`Wide-Grip Lat Pulldown` /
`Close-Grip Front Lat Pulldown`）、クローズグリップだけ別種目にすると
同じ「グリップ」という概念が軸と種目名に二重に現れる。
`movementPattern` も可動域も変わるので、揃えて別種目にする。

## §2 Q2 との関係

Q2 は「器具・**グリップ**を独立軸として扱えるか」と両方を並べているが、
**この 2 つは性質が違う。**

クローズグリップベンチを「ベンチプレスの一形態」として畳むと、
三頭の種目が胸の種目として提案される。器具では同じことが起きない。

Q2 が実際に検証しているのは「**主働筋が入れ替わらない差異を潰す近似が実用に耐えるか**」である。

## 影響

- 器具の切り替えは UI 上「実行方法の選択」であり、カバレッジ図は変化しない
- §6 の差分表示は**種目の差し替え時のみ**発生する。器具の切り替えでは差分が出ない。
  UI 上これが分かるようにする（器具切り替えでカバレッジ図がピクリとも動かないと、
  壊れていると誤解される）

## 未解決

- **ワイドグリップを軸にするか別種目にするか。** 上流の primary は変わらないが、
  実感としては大胸筋の外側寄りになる。§4.3 のタキソノミーは胸を上部/中下部でしか
  分けていないので、そもそも表現できない。**表現できない差異は軸に畳むのが一貫している**
- スミスマシンは実質 bilateral 固定であり、`lateralityOptions` との組み合わせに無効なものが出る。
  これは Q2 の検証対象そのものなので、重みではなく**組み合わせバリデーション**の側で扱う
