# ADR 0002: 器具を変更しても muscleWeights は変えない（v1）

- ステータス: **Proposed**（M0 で確定させる）
- 日付: 2026-08-17
- 関連: design.md §4.5, §4.2

## 背景

ダンベルベンチプレスはバーベルベンチプレスより安定性の要求が高く、
三角筋前部の関与比率が上がる。同じことがスミスマシン（比率が下がる）にも言える。
`equipmentOptions` を独立軸に分離した以上（§4.2）、
「器具を変えたら重みも変わるべきでは」という問いが必ず出る。

## 決定（案）

**v1 では変えない。器具は重みに影響しない独立軸として扱う。**

必要になった時点で `equipmentModifiers` を後付けする。

```jsonc
// 将来の拡張形（v1 では実装しない）
"equipmentModifiers": {
  "dumbbell": { "deltoid_anterior": 1.2, "pectoralis_major_sternal": 0.95 }
}
```

## 理由

1. **検証対象がぼやける。** Q1（重み付けデータは「特に効く部位」を表現できるか）を検証している最中に
   器具修正係数を入れると、違和感の原因がベース重みなのか修正係数なのか切り分けられなくなる
2. **データ量が掛け算で増える。** 800 種目 × 平均 3 器具 = 2,400 件の重みセットを
   M2 の決定論ベースラインで生成しても、M5 の人力レビューが回らない
3. **修正係数の根拠がない。** ベース重みには free-exercise-db の `mechanic` と primary/secondary という
   出発点があるが、器具修正係数にはそれがなく、完全な当て推量になる

## 影響

- 器具の切り替えは UI 上「実行方法の選択」であり、カバレッジ図は変化しない
- §6 の差分表示（「フライ → ディップスに変更 / 三頭 +0.18」）は**種目の差し替え時のみ**発生する。
  器具の切り替えでは差分が出ない。UI 上これが分かるようにする（器具切り替えでカバレッジ図が
  ピクリとも動かないと、壊れていると誤解される）

## 未解決

- スミスマシンは実質 bilateral 固定であり、`lateralityOptions` との組み合わせに無効なものが出る。
  これは Q2（無効な組み合わせが検出できるか）の検証対象そのものなので、
  重みではなく **組み合わせバリデーション** の側で扱う
