# ADR 0011: 多様性項がどの種目に加点を払うか

- ステータス: **Accepted**
- 日付: 2026-08-21
- 関連: ADR 0008

## 背景

ADR 0008 は多様性を distinct な動作パターン数への加点として書くと決めた。
どの種目を数えるかは決めていない。

`MOVEMENT_PATTERNS` に `throw` と `jump` を置いたのは 72 レコードが `other` に落ちるのを防ぐためで、
刺激の種類として置いたものではない（`packages/data/src/axes.ts`）。
この 2 つは 51 件中 47 件がプライオメトリクスだが、**残り 4 件は上流が `strength` としている**
（ウインドスプリント、パイレーツシップ、スラム、バトリングロープ）。

種類数に数えると、多様性項は必ずそこへ手を伸ばす。
無作為 120 要求（対象部位 1〜4、種目数 3〜6）で測ると:

```
plyometrics を含む結果   30/120 ケース、延べ 38 種目
オーバーヘッドスラム単体   9/120 ケース
```

## 決定

**次のどちらかに当たる種目を多様性項の種類数に数えない。**

- カテゴリが `plyometrics`
- 動作パターンが `throw` または `jump`

候補プールからは外さない。カバレッジ項で勝つなら選ばれる。

## 理由

### カバレッジを犠牲にしていない

| 方針 | Σ√ の平均 | 動作パターン数 | 1 種類だけの結果 | plyo 延べ | `throw` / `jump` 延べ |
|---|---|---|---|---|---|
| 現状 | 3.0937 | 4.41 | 0 件 | 39 | 48 |
| `throw` / `jump` を数えない | 3.0916 | 4.33 | 0 件 | 18 | 5 |
| プライオメトリクスを数えない | 3.0981 | 4.33 | 0 件 | 3 | 26 |
| `strength` 以外を数えない | 3.1010 | 4.25 | 0 件 | 3 | 26 |
| 対象寄与 0.5 未満を数えない | 3.1078 | 4.26 | **3 件** | 37 | — |
| **両方を数えない（採用）** | **3.0948** | **4.28** | **0 件** | **3** | **5** |

ADR 0008 が守る「全種目が同じ動作パターンになる結果が出ない」は保たれる。

### なぜ片方では足りないか

動作パターンだけで切ると、プライオメトリクスが 18 件残る。
`horizontal_pull` のムービングクローシリーズ、`horizontal_press` のリターンプッシュのように、
一般的な動作パターンを持つ種目が加点を受け続ける。

カテゴリだけで切ると、`throw` / `jump` の選択が 48 件から 26 件にしか減らない。
**上流が `strength` としている 4 件が加点を引き継ぐ。**

```
plyometrics だけを数えない場合に throw / jump を埋める種目
  ウインドスプリント  13/120  [strength / jump]
  パイレーツシップ      9/120  [strength / throw]
  スラム                1/120  [strength / throw]
```

オーバーヘッドスラムが抜けた枠を、走るドリルとロープ種目が埋めるだけになる。

### なぜカテゴリ一律にしないか

`docs/data-survey.md` は `olympic_weightlifting` に一般的な筋力種目が 10 件以上混ざっていること、
`strongman` にしか `carry` が存在しないことを記録している。
**`category` は上流のラベルで、当てにならない。**
一律で切ると `lower_body` からパワークリーンが落ちるのを実測した。

プライオメトリクスは定義が「跳ぶ・投げる」で、筋力種目の紛れ込みが構造的に少ない唯一のカテゴリ。

### なぜ対象寄与で門を作らないか

Issue #64 が挙げた案だが、測ると 1 種類だけの結果が 3 件出る。
**多様性項の存在理由そのものを壊す。**

### 候補から外さない理由

`docs/data-survey.md` は「カテゴリ単位で切ると中身の例外を落とす」として、
プライオメトリクスの一律除外を否決している。内転筋 primary の 6 件中 4 件がこのカテゴリにある。

多様性項で数えないのは候補プールの話ではない。
内転筋を指定した要求で出力が変わらないことを確認した。
ラテラルバウンドとカリオカクイックステップは、加点なしでもカバレッジで勝って選ばれる。

## 影響

- ゴールデンセット 5 件のうち 3 件は変わらない。
  `ppl_push` と `ppl_pull` はカバレッジ項が約 1% 落ち、プライオメトリクスが 1 件ずつ抜ける。
  **無償ではない。** 対象部位への寄与の合計も 6.00 から 5.88 / 5.80 に下がる
- 目的関数が `category` を参照するようになる。
  上流のラベルの品質が選択結果に効く経路が 1 つ増える
- `throw` と `jump` は、多様性項に対しては存在しない分類になる。
  順序付け（ADR 0009）と表示では引き続き使う
- 上流の `category` が誤っている種目は、動作パターン側の網でしか捕まらない。
  ウインドスプリントが `strength` なのは上流のラベルの問題で、そちらを直す判断とは別
