# data/

データセット本体。**このリポジトリで最も資産価値が高い部分。**

日本語名がついた種目データセットも、重み付き（連続値）のものも、
器具軸が分離されたものも現存しない（design.md §11）。

## 構成

| パス | 内容 | コミット |
|---|---|---|
| `upstream/` | free-exercise-db の生データ（873 件） | しない。`pnpm data:fetch` で再現する |
| （未作成） | 拡張スキーマに変換した種目データ | する。M1〜M2 で生成 |

上流をコミットしないのは、ライセンス上の理由ではなく（Unlicense なので再配布は自由）、
取得スクリプトで再現できるものをリポジトリに二重に置く理由がないため。

## 上流の実測

873 件の分布・欠損・タキソノミーとのギャップは [../docs/data-survey.md](../docs/data-survey.md)。
M1・M2 の作業量見積もりはこの数字を前提にしている。

## スキーマ

型定義とバリデーションは `packages/data/src/schema.ts`。
`muscleWeights` の合計は 1.0 に正規化する（許容誤差 1e-6）。

Unlicense（パブリックドメイン）。上流の
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) が Unlicense のため、
